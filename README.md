## Task Manager Agile

Projeto desenvolvido para a disciplina de Engenharia de Software.

# Objetivo

Desenvolver um sistema simples de gerenciamento de tarefas utilizando conceitos de metodologias ágeis, versionamento de código e integração contínua.


# Funcionalidades

- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Remover tarefas
- Definir prioridade das tarefas


# Tecnologias Utilizadas

- Java
- Git
- GitHub
- GitHub Actions


# Estrutura do Projeto

src/
├── model/
│ └── Task.java
├── service/
│ └── TaskService.java
└── Main.java


# Metodologia Ágil

O projeto foi organizado utilizando Kanban no GitHub Projects, dividido nas colunas:

- To Do
- In Progress
- Done


# Integração Contínua

Foi configurado GitHub Actions para automatizar a compilação do projeto a cada push realizado na branch principal.


# UML

O projeto possui:

- Diagrama de Casos de Uso
- Diagrama de Classes

Os diagramas representam a estrutura do sistema e suas funcionalidades principais.


# Mudança de Escopo

Durante o desenvolvimento foi adicionada a funcionalidade de prioridade nas tarefas, permitindo melhor organização das atividades do sistema.


# Exemplo de Funcionalidades

O sistema permite que o usuário:

1. Crie tarefas pelo terminal
2. Liste tarefas cadastradas
3. Atualize informações das tarefas
4. Remova tarefas
5. Defina prioridades
